# Role Loop entry for Mistral Vibe

These are ordinary files, not native Vibe agent profiles. Use [core/loop.md](core/loop.md)
as the sole routing norm and load the selected role/contracts from this package.
The human carries contract artifacts, runs tests and Git, and records actual
human decisions and issue/PR feedback. Never invent approval or merge.

Use a new invocation for each initial role and each repair reviewer. Initial
review receives only C5 core, criteria, exact product and readable norms/decisions;
repair mode adds the explicit previous-blocker/diff/coverage/counter appendix.
Keep author history and other initial verdicts outside project instructions.
A fresh conversation still loads configured instructions and can read reachable
files. A role prompt is not access control; explicit tool selection is not an OS
sandbox. Inventory configuration and trust before execution. No shell, task,
connectors or MCP in this route. Tests and Git are human actions.
