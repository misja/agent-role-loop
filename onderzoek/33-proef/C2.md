# C2 — W1 Build Packet

## Summary

Add optional `alleen_beschikbaar=False` to `Boekenplank.lijst()` so callers can request available books while preserving insertion order, stored books and loan status. This packet agrees with the concrete approved design in `work-items/W1/approved-design.md`; no changed goal, interface, scope, norm or risk choice requires a new human decision.

## Goals

1. Preserve the default listing of all books in insertion order.
2. Return only books whose `uitgeleend_aan is None` when filtering is enabled.
3. Return `[]` for an empty shelf or a filtered shelf containing only loaned books.
4. Preserve stored books and loan status during filtering.

## Proposed approach

Change only `Boekenplank.lijst()`:

```python
def lijst(self, alleen_beschikbaar=False):
    if alleen_beschikbaar:
        return [b for b in self._boeken if b.uitgeleend_aan is None]
    return list(self._boeken)
```

The comprehension preserves insertion order and returns a new list containing existing book objects without changing shelf contents or loan fields. The default branch retains the existing implementation.
