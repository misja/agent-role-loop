## Summary
Add an optional `alleen_beschikbaar=False` parameter to the `lijst()` method in `boekenplank.py` to enable filtering books by availability while preserving insertion order and existing book/loan state. This change satisfies S1-S4 acceptance criteria defined in C0 and matches the concrete approved design in work-items/W1/approved-design.md.

## Goals
1. S1: Default behavior returns all books in insertion order when `alleen_beschikbaar=False` or no argument.
2. S2: When `alleen_beschikbaar=True`, return only books where `uitgeleend_aan is None`, preserving insertion order.
3. S3: Return empty list `[]` for empty plank or when all books are loaned with `alleen_beschikbaar=True`.
4. S4: Filtering does not modify the stored books or their loan status.

## Non-goals
- Changing the export file format or storage mechanism.
- Modifying `controleer.py`, CLI, dependencies, or adding new files.
- Altering the `Boek` dataclass or `toevoegen()` method.
- Adding keyword-only arguments or changing the method signature beyond the approved design.
- Performance optimization beyond the filtering requirement.
- Changing sorting behavior or data structures.

## Current state
`boekenplank.py:24-25` defines `def lijst(self): return list(self._boeken)` with no parameters. `controleer.py` defines four test cases (S1-S4) that call `lijst(alleen_beschikbaar=True)` and `lijst()`. Running `python3 -B controleer.py werk volledig` currently produces 1 pass (S1) and 3 TypeError failures (S2-S4) with exit code 1 because the `lijst()` method does not accept the `alleen_beschikbaar` parameter. The `Boek` dataclass in `boekenplank.py:8-12` has `nummer: int`, `titel: str`, `uitgeleend_aan: str | None = None`. The `Boekenplank` class stores books in `self._boeken` list preserving insertion order.

## Proposed approach
Modify the `lijst()` method signature to `def lijst(self, alleen_beschikbaar=False):`. When `alleen_beschikbaar` is `True`, return a new list comprehension `[b for b in self._boeken if b.uitgeleend_aan is None]`; otherwise return `list(self._boeken)` unchanged. This approach uses the existing `Boek.uitgeleend_aan` field without modifying any other code, tests, or dependencies. The solution is a thin slice matching the concrete approved design exactly.

## Acceptance criteria
1. S1: `lijst()` with no arguments or `alleen_beschikbaar=False` returns all books in insertion order `[1, 2, 3]` for the test fixture. Assigned to strict reviewer.
2. S2: `lijst(alleen_beschikbaar=True)` returns only books with `uitgeleend_aan is None` in insertion order `[1, 3]` for the test fixture. Assigned to strict reviewer.
3. S3: `lijst(alleen_beschikbaar=True)` returns `[]` for empty plank and for plank with all books loaned. Assigned to strict reviewer.
4. S4: Calling `lijst(alleen_beschikbaar=True)` does not alter the internal `_boeken` list or any book's `uitgeleend_aan` value. Assigned to strict reviewer.
